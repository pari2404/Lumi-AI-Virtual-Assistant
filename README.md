# ✨ Lumi — AI Voice Assistant

> A modern voice-enabled AI virtual assistant built with React.js and Gemini API.

Lumi is an interactive AI voice assistant that allows users to communicate naturally using their voice. It combines Google's Gemini API with browser-based Speech Recognition and Text-to-Speech to create a conversational assistant with dynamic voice interactions and a responsive interface.

---

## 🚀 Overview

Lumi listens to the user's voice, understands the command or question, and responds either by performing a predefined action or generating an AI-powered response.

The application follows a simple interaction flow:

**🎤 Speak → 🧠 Understand → ⚡ Process → 🤖 Respond → 🔊 Speak**

This project was built to explore AI integration, browser APIs, React state management, and interactive frontend development.

---

## ✨ Features

### 🎤 Voice Interaction
- Speech-to-text using the browser's Web Speech API
- Text-to-speech responses using Speech Synthesis
- Supports natural voice-based interaction

### 🤖 AI-Powered Conversations
- Integrated Gemini API for intelligent responses
- Handles general questions and conversational prompts
- Automatically converts AI responses into speech

### 🌐 Voice Commands
Lumi can perform predefined actions such as:

- Open YouTube
- Open Google
- Search YouTube
- Search Google
- Get the current date
- Get the current time

### 🎨 Interactive UI
- Dynamic listening animation
- AI response animation
- Conditional rendering based on assistant state
- Voice-friendly response display
- Clean and responsive interface
